## 真实 Finder 验收

所有新建文件操作在项目内独立临时目录进行，不改动用户原有文件。

- **冷启动通过**：无当前宿主进程时，真实 Finder 空白右键“快速导航”；同一请求 ID 依次出现在扩展发出、宿主启动并消费待处理请求、面板显示日志中。宿主来自当前安装路径。截图和 AX 树看到卡片，未显示设置窗口；日志显示 Finder 保持前台。
- **菜单更新通过**：首次安装现场曾观察到两个“快速导航”；只停止目标路径扩展并重新注册后恢复一项。安装器补上该刷新步骤后重新安装，真实菜单仍只有一项本项目“快速导航”和对应“新建文件”子菜单。其他软件自己的“新建文件”入口不属于重复安装。
- **新建与选中先失败后通过**：首次冷启动创建 TXT 成功，但即时前台检查误报 `finderNotFrontmost`。去掉针对定向 Apple Event 的同步前台假设后，再次从真实菜单冷启动创建 `未命名 2.txt`；磁盘仅新增一份，Finder AX 树明确显示该文件已选中，无选中失败日志。
- **现场恢复**：关闭本轮最后一个验收窗口，用户其他 Finder 工作窗口保留；应用更新保留在当前安装位置。原有收藏和设置未修改。

## 证据边界

- 全量 smoke 中的导航策略、分页保持、路径复制等结果属于自动回归。本轮未重新完成卡片全部按钮的独立人工矩阵。
- UI 自动化在选取后台宿主控件时曾转到设置窗口，因此没有据此宣称“最近访问 → 上一级”的本轮端到端验证通过。
- 双屏、完整四角/深色模式矩阵、Intel/macOS 14 实机和长时 Instruments 观察未执行。
- 路径搜索未实现；卡片仅保证屏幕边界处理，不能保证不遮挡每个文件图标。
- 本轮为本机开发签名构建，没有生成或公证面向所有用户的二进制发行包。

## 复现命令

在仓库根目录执行：

```bash
zsh FinderQuickNav/scripts/run-tests.sh
FQN_CONFIGURATION=Release zsh FinderQuickNav/scripts/build-local.sh
zsh FinderQuickNav/scripts/install-local.sh
zsh FinderQuickNav/scripts/verify-extension-registration.sh
```

构建需要已有签名身份；其他机器先阅读 README 的签名说明。自动回归不要求在本机安装扩展。
