## 右键菜单上移的边界

“快速导航”原本就是 `FinderSync.menu(for:)` 返回菜单的第一项，本扩展的“新建文件”在其下方。实际 Finder 菜单中，本扩展仍位于其他软件扩展之后。

查阅 [Apple Finder Sync 文档](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html) 和本机 SDK 的 `FIFinderSync` 协议后，未发现指定整个 Finder 菜单顺序或插入全局索引的公开接口。因此本次未实现跨系统项或其他扩展的入口上移，也未修改其他软件设置。

屏幕四角与负坐标屏幕是算法测试；双屏实机、完整深色/四角 UI 矩阵及长时性能仍未纳入此次验收。
