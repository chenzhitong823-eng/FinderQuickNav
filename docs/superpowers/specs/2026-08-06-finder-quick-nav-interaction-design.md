# Finder QuickNav 交互与设置增量设计

## 目标

在已完成的方案 C 原生 Finder 工具上，修复快速导航卡片的连续操作体验，并增加一个可进入的平铺式设置窗口，用来管理快速导航、个人收藏和新建文件菜单。

本轮不重做 Finder Sync bridge、当前窗口导航、基础收藏存储和新建文件底层服务，也不加入“发送到”文件移动/复制功能。

## 用户已确认的行为

### 1. 卡片生命周期

- 卡片打开后可以拖动；拖动手柄是卡片顶部标题区域。
- 卡片打开期间保留用户拖动后的位置；下一次从 Finder 右键打开时重新按低遮挡规则定位。
- 点击卡片外部、按 Esc 或 Finder 不再是前台应用时关闭卡片。
- 点击“上一位置”、“上层文件夹”、收藏条目、最近访问条目或路径段后，卡片保持打开。
- 导航成功后读取当前 Finder 窗口目录，刷新标题、路径、收藏状态和列表；不新增 Finder 窗口。
- 导航失败时保留卡片并显示可读错误，用户可以继续尝试其他操作。

### 2. 文案和路径

- 原“返回”改为“上一位置”，避免与关闭卡片混淆。
- 原“上一级”显示为“上层文件夹”，突出它是目录层级操作。
- 未悬停时路径区域只显示房子图标和当前文件夹名称。
- 鼠标悬停路径区域时显示从根目录到当前目录的完整本地路径；路径段可点击并作用于当前 Finder 窗口。
- 路径过长时完整路径使用悬浮提示/小气泡展示，不改变紧凑卡片的固定高度。

### 3. 列表和过渡

- 收藏和最近访问仍为分页，一次只展示一组。
- 每个目录条目使用全宽 hit target；点击图标、名称、路径提示或该行空白都触发跳转。
- 鼠标悬停或按下时，整行显示 Finder 风格的强调色背景和白色文字；失焦后恢复普通样式。
- 分页切换和导航后的路径/列表刷新使用短时淡入、平移和选中反馈，不使用持续动画。

## 设置窗口

设置窗口采用左侧模块列表、右侧编辑区域的 macOS 原生平铺结构。首批模块为：

1. 快速导航：启用/停用“上一位置”“上层文件夹”“路径悬停完整显示”，设置默认分页和“导航后保持打开”。
2. 个人收藏：添加目录、编辑显示名称、拖动排序、启用/停用和删除；失效路径保留并显示状态。
3. 新建文件：管理现有文件夹、TXT、Markdown、Word、Excel、PowerPoint 六种入口的启用状态和顺序。
4. 权限与扩展：展示 Finder 扩展、辅助功能和 Finder 自动化授权状态，并提供进入系统设置的按钮。

右键卡片底部的“管理收藏…”直接打开设置窗口的“个人收藏”模块。设置数据使用 App Group UserDefaults，使宿主应用与 Finder Sync Extension 能共享新建文件入口配置；点击事件仍继续使用现有 DistributedNotificationCenter bridge。

## 技术边界

- 面板仍是 `.borderless + .nonactivatingPanel` 的 `NSPanel`，不激活宿主应用。
- 面板外点击使用本地和全局鼠标事件监视器；监视器只在卡片显示期间注册，关闭时移除。
- 面板拖动使用 AppKit 的窗口移动能力，不把按钮区域变成拖动区域。
- “上一位置”按 Finder 原生历史执行；执行后延迟读取当前 Finder target 以刷新卡片。
- 配置模型、路径展示模型和收藏排序逻辑必须有独立 smoke test；真实 Finder 权限和窗口行为继续用现有实机验收。
- 不复制 iRightMouse 或 Menuist 的源代码、资源或闭源实现；只借鉴其模块化设置窗口的组织方式。

## 验收标准

- 面板可从顶部拖动到新位置，按钮仍可正常点击。
- 面板外单击会关闭；面板内单击不会误关闭。
- 连续执行两次或以上导航动作时卡片持续存在，标题和路径跟随 Finder 更新。
- 默认路径只显示当前目录，悬停可看到完整根路径。
- 点击收藏/最近访问任意整行的空白区域也能跳转，并出现蓝底白字反馈。
- 设置窗口可以修改收藏显示名和顺序；重启宿主后修改仍存在。
- 设置窗口可以关闭至少一种新建文件类型，Finder 背景右键菜单同步隐藏该类型；重新启用后恢复。
- 现有 bridge、导航、存储、新建文件和 Release 回归不退化。
